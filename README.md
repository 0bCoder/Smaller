# [Smaller]!

[Smaller] is an image compression web app that reduces image sizes through numerous formats. Smaller is a Chinese edition os Squoosh.

# Privacy

Smaller does not send your image to a server. All image compression processes locally.

However, Smaller utilizes Google Analytics to collect the following:

- [Basic visitor data](https://support.google.com/analytics/).
- The before and after image size value.
- If Smaller PWA, the type of Smaller installation.
- If Smaller PWA, the installation time and date.

# Developing

To develop for Smaller:

1. Clone the repository
1. To install node packages, run:
   ```sh
   npm install
   ```
1. Then build the app by running:
   ```sh
   npm run build
   ```
1. After building, start the development server by running:
   ```sh
   npm run dev
   ```
